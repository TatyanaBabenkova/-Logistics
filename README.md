# От приёмки до цеха — рисованный мультфильм

**[Открыть мультфильм](https://tatyanababenkova.github.io/-Logistics/)**

Версия 02 от 03.10.2026. Два сюжета по 44 секунды: крытый грузовик и тягач с тележками. Пять сцен: подготовка груза, поездка по территории, передача у цеха, внутренний робот, прибытие к линии.

Рисунки созданы встроенным инструментом генерации изображений по фотографиям техники из аналитической записки v02. Движение и монтаж выполнены программной анимацией; MP4 экспортированы тем же рендерером. Это не нейросетевая генерация движения из текста. Ролики без звука, с русскими подписями.

## Просмотр

Откройте `index.html` в браузере. Интернет не нужен для локального просмотра. Кнопки запуска, паузы, повтора, скорости, выбора транспорта и полного экрана расположены над картинкой. Выбор сцены и перемотка доступны ниже.

MP4: `media/logistics-truck-v02.mp4` и `media/logistics-tug-v02.mp4`. Формат H.264, 1280×720, 24 кадра/с, 44 секунды. Видео можно скачать со страницы.

## Состав

- `index.html`, `style.css`, `app.js` — страница и управление просмотром.
- `film.js` — общий рендерер анимации для браузера и экспорта видео.
- `assets/` — рисунки и кадр обложки.
- `media/` — два готовых ролика.
- `ARTWORK.md` — происхождение рисунков и набор запросов для генерации.

## Границы демонстрации

Предприятие условное. Рисунки машин передают характерные формы, но не являются точными моделями оборудования. Погрузка и выгрузка разделены монтажными переходами; их механика здесь не проектируется. Роботизированная платформа показана только внутри цеха. Доставка к линии не означает автоматическое снятие коробок: эту операцию выполняет оператор или отдельная станция.

Климатическая пригодность, сервис, безопасность, парк и экономика определяются обследованием и испытаниями. Аналитическая записка v02 не изменена при создании мультфильма.
