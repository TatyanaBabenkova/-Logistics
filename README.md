# Логистика действующего предприятия

Интерактивная демонстрация **v01 от 03.10.2026**: приёмка у въезда → улица → склад → цех → готовая продукция → возврат тары.

**Открыть демонстрацию после включения GitHub Pages:** https://tatyanababenkova.github.io/-Logistics/

Три варианта: крытый автономный грузовик, уличный тягач с тележками, смешанная схема с водителем на улице. Кнопки запуска, паузы, выбора этапа, изменения скорости и ручного подхвата при остановке уличного автопилота.

## Локальный запуск

Откройте `index.html` в браузере. Установка и интернет для анимации не нужны. Внешние ссылки ведут на первоисточники. Также подходит любой статический HTTP-сервер.

## Публикация

В GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save. После первой сборки станет доступна ссылка выше.

## Содержание

- `index.html` — интерфейс, схема и ссылки на источники.
- `style.css` — оформление для компьютера и телефона.
- `app.js` — анимация и переключение сценариев.
- `.nojekyll` — статическая публикация без обработки Jekyll.

Это поясняющая концепция, не цифровой двойник, не модель безопасности и не расчёт производительности. План, расстояния, времена, груз и номера партий условные. Погрузка и передача в здании — отдельные операции. Ручной подхват требует подтверждения диспетчера. Климатическая пригодность оборудования должна быть проверена на объекте.

Иллюстрации в анимации — условные схемы типов машин, не точные изображения моделей. Фотографии оборудования с указанием происхождения включены в отдельную аналитическую записку v02, хранящуюся в локальном проекте.
