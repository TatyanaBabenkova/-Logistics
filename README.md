# Интерактивная презентация логистики

Версия 04 • 4 октября 2026. Рабочий прототип интерфейса, содержание предварительное.

[Открыть презентацию](https://tatyanababenkova.github.io/-Logistics/)

Заставка объясняет управление. Сверху — Процесс, Техника, Управление и внедрение. Слева выбирают раздел, в центре исследуют условный план или устройство, справа читают пояснения.

Последовательный просмотр останавливается на выборе приёмки. Нажатие на объект ставит показ на паузу. Сравнение: разгрузка у складов / общий пункт приёмки. Во вкладке управления показано условное задание, выбор исполнителя, объезд и этапы подключения участков. Это не действующая диспетчерская платформа и не расчёт экономической эффективности.

Карточки техники содержат сохранённые рисунки и ссылки на первоисточники; невыбранный погрузчик обозначен как условный.

На компьютере интерфейс занимает высоту окна. На небольшом экране боковые панели открываются кнопками. При очень маленькой высоте подробности могут прокручиваться внутри правой панели; вся страница остаётся фиксированной.

Для запуска без интернета открыть index.html из распакованной копии.

## Файлы

- content.js — предварительные тексты, роли объектов и источники.
- interface.js — навигация, интерактивная карта, состояния и показ.
- interface.css — адаптивная компоновка.
- movie-v03.html — предыдущий фильм 2:16.
- pilot/ — 18-секундная 3D-проба.
- ARTWORK.md — происхождение прежних рисунков.

Условная карта построена из редактируемых SVG-элементов. План не является реальной схемой предприятия; расстояния, объекты и маршруты демонстрационные.
